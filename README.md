# SQL Project – Data Job Market Analysis

## Project Overview

This project analyzes data job postings using SQL to identify trends and insights in the data analyst job market.

The analysis focuses on companies, job postings, salaries, required skills, and education requirements.

## Project Objectives

* Analyze the data analyst job market
* Identify companies with the highest number of job postings
* Analyze salary information
* Identify the most requested skills
* Examine education requirements
* Extract business insights from job posting data

## Tools & Technologies

* PostgreSQL
* SQL
* Git & GitHub

## Dataset

The dataset contains information about job postings, companies, skills, salaries, and education requirements.

The raw CSV files are kept locally and are not included in this repository because of their file size.

## Goal

The goal of this project is to demonstrate practical SQL and data analysis skills through a realistic business-oriented dataset.
